# AxDiscordLink 🛠️

> This plugin has not released yet, some things are subject to change!
{style="warning"}

### What is AxDiscordLink?
- An all-in-one Discord - Minecraft linking and 2FA plugin.

## Most Important Features
- Supports Spigot, Paper, Folia, Velocity and Bungeecord servers.
- Self Hosted: The bot is run from your Minecraft server and your Discord account.
- Easy Setup: Follow the guide on the wiki to set up the plugin in 5 minutes.
- Role Sync: Create mappings between Discord role and Minecraft groups and the bot can handle syncing them both ways. (Requires LuckPerms)
- Name Sync: If enabled, the plugin can automatically rename Discord users on your guild to their Minecraft name.
- 2FA: Use the builtin two-factor authentication system to secure your Minecraft account using Discord confirmations.
- Special Access: Create a list of users who can play on your server.
- Discord Commands: It is possible to check the user's profile, linking details from discord.
- Admin Utilities: Manually link, unlink or disable the 2FA of users.
- Embed Builder: Customize any Discord message sent by the plugin to your liking. All discord formatting features are supported.
- Rewards: Run commands or give items to players when they link, unlink, boost your server.
- Customizable Bot: You can change the activity, online status displayed by the Discord bot.
