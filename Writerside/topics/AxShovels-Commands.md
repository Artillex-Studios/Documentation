# Commands

| Command                                         | Permission                                       | Default  | Description            |
|-------------------------------------------------|--------------------------------------------------|----------|------------------------|
| /axshovels [help]                               | axtools.help                                     | true     | Help                   |
| /axshovels give &lt;player> [level]             | axtools.give                                     | OP       | Give shovel to player  |
| /axshovels tool setlevel &lt;level> [reset-xp]  | axtools.tool.setlevel                            | OP       | Set tool level         |
| /axshovels tool setxp &lt;xp>                   | axtools.tool.setxp                               | OP       | Set tool XP            |
| /axshovels tool setprestige &lt;prestige>       | axtools.tool.setprestige                         | OP       | Set tool prestige      |
| /axshovels reload                               | axtools.reload                                   | OP       | Reload configuration   |
| /axshovels essence view [player]                | axtools.essence.view, axtools.essence.view.other | true, OP | View essence balance   |
| /axshovels essence give &lt;player> &lt;amount> | axtools.essence.give                             | OP       | Give essence           |
| /axshovels essence take &lt;player> &lt;amount> | axtools.essence.take                             | OP       | Take essence           |
| /axshovels essence set &lt;player> &lt;amount>  | axtools.essence.set                              | OP       | Set essence            |
| /axshovels essence reset [player]               | axtools.essence.reset                            | OP       | Reset essence          |
| /axshovels essence pay &lt;player> &lt;amount>  | axtools.essence.pay                              | true     | Send essence to player |
| /axshovels xp view [player]                     | axtools.xp.view, axtools.xp.view.other           | true, OP | View player xp balance |
| /axshovels xp give &lt;player> &lt;amount>      | axtools.xp.give                                  | OP       | Give player xp         |
| /axshovels xp take &lt;player> &lt;amount>      | axtools.xp.take                                  | OP       | Take player xp         |
| /axshovels xp set &lt;player> &lt;amount>       | axtools.xp.set                                   | OP       | Set player xp          |
| /axshovels xp reset [player]                    | axtools.xp.reset                                 | OP       | Reset player xp        |
| /axshovels xp reset [player]                    | axtools.xp.reset                                 | OP       | Reset player xp        |
| /axshovels shop [player]                        | axtools.shop, axtools.shop.other                 | true, OP | Open shop gui          |
| /axshovels leaderboard [player]                 | axtools.leaderboard, axtools.leaderboard.other   | true, OP | Open leaderboard gui   |

> Note that the permissions start with `axtools`, not axshovels!
