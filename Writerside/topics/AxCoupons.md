# AxCoupons 🛠️

> This plugin has not released yet, some things are subject to change!
{style="warning"}

## What is AxCoupons?
- A lightweight redeemable coupon / voucher plugin with multi server support.

![image_46.png](image_46.png)

## Most Important Features
- H2 and MySQL databases supported.
- Multi Server Support: The plugin can be used on multiple servers connected to the same database.
- Unlimited Coupons: You can create as many coupons as you would like.

![image_50.png](image_50.png)
- Per Coupon Messages and Settings: You can create custom messages for all the coupons.
- One-Time and Refresing Coupons: Make coupons that can only be redeemed once or set a cooldown and make it redeemable multiple times after a specific cooldown.

![image_47.png](image_47.png)
- Permission Requirement: Make it that coupons require a permission to redeem.

![image_48.png](image_48.png)
- IP Limits: Define how many players can claim a coupon from the same IP to prevent abuse.
- Automated Coupons: Predefine when will a coupon become available and when will it expire.
- Command and Item Rewards: Coupons can give any kind of custom item, and they can also run commands.

![image_49.png](image_49.png)
- Customizable: You can change all messages and sounds.
